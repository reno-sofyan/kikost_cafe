## Kesimpulan untuk deployment

1. Reverse proxy = **Traefik milik Coolify** (`coolify-proxy`, network `coolify`).
   Tidak perlu memasang proxy sendiri. Stack POS menempel via label Traefik.
2. Konfigurasi: `PROXY_NETWORK=coolify`, `TRAEFIK_HTTPS_ENTRYPOINT=https`,
   `TRAEFIK_CERTRESOLVER=letsencrypt` (default `.env.example`).
3. DNS: tambah `A pos → 76.13.180.150`.
4. **Sebelum `docker compose up`**: SSH → `df -h /` (pastikan > 5 GB free),
   `docker network ls | grep coolify`, `docker ps` (nama Kikost, tak ada `cafe-pos-*`).
5. Firewall: jangan diubah.
6. CPU idle → aman build image di VPS kapan saja (tetap disarankan di luar jam sibuk).
